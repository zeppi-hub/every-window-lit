# Fonts

Used only to draw the sign and print textures (tools/textures.py); the fonts themselves are not shipped to the game.

- DejaVuSansCondensed-Bold.ttf, DejaVuSerif-Bold.ttf: DejaVu Fonts (https://dejavu-fonts.github.io), Bitstream Vera Fonts licence with DejaVu changes in the public domain (https://dejavu-fonts.github.io/License.html).
- LiberationSansNarrow-Bold.ttf: Liberation Fonts (https://github.com/liberationfonts/liberation-fonts), SIL Open Font License 1.1 (https://openfontlicense.org).
